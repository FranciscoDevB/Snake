#  Jogo da Cobrinha (Snake) em C#

Projeto desenvolvido em **C#** para o console do Windows, aplicando conceitos fundamentais de Programação Orientada a Objetos (POO), estruturas de dados (`List<T>`), controle de fluxo e manipulação de coordenadas no terminal.

## Funcionalidades
- Movimentação fluida com as setas direcionais do teclado.
- Sistema de colisão com as paredes e com o próprio corpo da cobra.
- Mecânica de crescimento dinâmico ao consumir a comida (`*`).
- Telas de Game Over centralizadas e tratamento de exceções de limites.

## Tecnologias Utilizadas
- **Linguagem:** C# (.NET 10)
- **Ambiente:** Console do Windows (Windows Terminal / PowerShell)
- **Controle de Versão:** Git & GitHub
